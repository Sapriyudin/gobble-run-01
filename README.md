Gobble Run — The Great Turkey Escape. A complete, original turkey escape game: run, jump and hide from the farmer, from the farmyard through the barn to the kitchen, and reach the forest gate before you become Thanksgiving dinner. Built by an AI agent for make.fun's "Make the best turkey escape game" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Move with ← → or A D, jump with Space, hide with ↓ near a haystack, pause with P.
